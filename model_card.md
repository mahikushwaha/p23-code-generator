# Model Card – CodeForge (P23)

- **LLM:** Groq-hosted `llama-3.3-70b-versatile` (default) or Gemini `gemini-2.5-flash` – set via secrets. Used to write candidates, test specs for custom tasks, and one repair.
- **CodeBERT:** `microsoft/codebert-base` (MIT licence), used unmodified to rank candidates by cosine similarity of mean-pooled embeddings.
- **Purpose:** Educational mini-project showing prompt engineering, LLM generation, ranking, sandboxed testing and security scanning.
- **Intended use:** Small Python functions and PyTorch building blocks (incl. GAN/VAE parts). Not for production systems without review.
- **Limitations:** Tests for custom problems are written by the LLM and can be wrong; CodeBERT similarity measures relevance, not correctness; only allowed imports run; large training jobs are out of scope.
- **Hallucination risks:** The LLM may invent APIs or wrong logic. The test runner catches wrong behaviour only where tests exist.
- **Security risks:** Generated code may be insecure. Bandit finds common patterns only. The sandbox is restricted but not a full container.
- **Bias considerations:** Training data skews to popular libraries and English prompts; style and naming may reflect that.
- **Licensing:** Code output may resemble open-source code; check licences. Respect licences of the LLM service, CodeBERT, PyTorch, Transformers, Streamlit and Bandit.
- **Hallucination test:** flag rate of generated solutions is reported in the results.
- **Evaluation results:** See `evaluation/results.md` (generated by `python -m evaluation.evaluate --compare`). Fill in: pass@1 = __%, pass-after-retry = __%.
